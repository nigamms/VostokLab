# VostokLab

**AI-Sana Shakarim Solveathon: AI & Medicine 2026 — школьный трек**  
Команда VostokLab, школа № 12, г. Семей.

## 1. Назначение проекта

VostokLab — Android-приложение для поддержки врача при анализе походки детей с детским церебральным параличом (ДЦП). Прототип обрабатывает предоставленные организаторами CSV-файлы, сравнивает три условия ходьбы — Baseline (обычная ходьба), Verbal (вербальная обратная связь) и VR (обратная связь через виртуальную реальность) — и формирует понятную аналитическую сводку.

Приложение поддерживает русский и казахский языки.

## 2. Установка и запуск APK

**Требования:** Android 8.0 (API 26) или новее; для онлайн-ИИ требуется интернет. Для голосового ввода необходимо разрешение на использование микрофона.

1. Установите APK VostokLab на Android-устройство. При необходимости разрешите установку приложения из выбранного источника.
2. Запустите VostokLab и выберите язык в настройках.
3. На главной странице нажмите «Выбрать файлы» и загрузите предоставленный архив `gait-cp-dataset.zip` либо все шесть CSV-файлов исследования.
4. После импорта откройте раздел «Участники», выберите участника и перейдите в раздел «Анализ». Можно также просмотреть сводку по всей группе.
5. В разделе «ИИ» задайте вопрос по результатам исследования текстом или голосом. Для проверки онлайн-подключения используйте соответствующую кнопку в настройках.
6. При необходимости сохраните PDF-отчёт через раздел анализа. Документация и методика доступны в настройках приложения.

Собственный сервер для работы приложения не требуется. Анализ CSV и построение графиков выполняются локально. Доступность онлайн-ИИ зависит от интернет-соединения, настроенного API-ключа и внешнего сервиса. Голосовой ввод зависит от доступности используемого сервиса распознавания речи.

## 3. Основные возможности

- Импорт исследовательских CSV и ZIP; выбор участника и сравнение трёх условий ходьбы.
- Интерактивные биомеханические графики, статистические показатели и сравнение относительно Baseline.
- Аналитическая сводка для отдельного участника и всей группы, пояснения возможных компенсаторных изменений.
- ИИ-ассистент, использующий рассчитанную сводку исследования; голосовой ввод.
- Экспорт PDF, обучающие подсказки, светлая и тёмная темы, встроенная документация.

## 4. Методика и результат исследования

Приложение группирует данные по участникам и условиям ходьбы, рассчитывает индивидуальные средние и сравнивает показатели. Групповые средние рассчитываются с равным весом участников. GPS (Gait Profile Score) отражает общее отклонение походки от эталонного паттерна, GVS (Gait Variable Score) — отклонение отдельных параметров движения. Исходные значения GPS/GVS берутся из предоставленных данных и агрегируются приложением.

На предоставленном наборе из 29 участников и 2 606 циклов шага получены следующие групповые средние (округлённые):

| Показатель | Baseline | Verbal | VR |
| --- | ---: | ---: | ---: |
| aMinSagH, ° | 6,17 | 2,67 | 2,00 |
| GPS, ° | 9,98 | 11,07 | 10,89 |

Разгибание бедра увеличилось при обратной связи, однако общий GPS вырос относительно Baseline. Это может указывать на компенсаторные изменения. Их механизм не доказан, а статистическая и клиническая значимость этих описательных различий не установлена. Нельзя считать VR однозначно лучшим условием для всех участников.

## 5. Использованные инструменты ИИ и технологии

- ChatGPT (OpenAI) — помощь при проектировании, создании и исправлении кода, подготовке интерфейса и конкурсных материалов.
- OpenRouter Chat Completions API — текстовый ИИ-ассистент; модель по умолчанию `openai/gpt-4.1-mini`, настраивается при сборке.
- OpenAI `gpt-live-transcribe` — опциональный потоковый голосовой ввод при наличии отдельного ключа; иначе используется системное распознавание речи Android при его доступности.
- Kotlin, Android Studio, Android SDK, Jetpack Compose / AndroidX, OkHttp, kotlinx.coroutines, Android PdfDocument.
- Python / scikit-learn использовались в исследовательском эксперименте по классификации условий ходьбы; эта модель не входит в APK как медицинский классификатор.

Расчёты выполняет программный модуль, а языковая модель помогает объяснять результаты. Проект не заявляет о создании собственной клинически валидированной нейросети.

## 7. Безопасность, ограничения и развитие

VostokLab — исследовательский прототип, а не медицинское изделие с подтверждённой клинической эффективностью. Он не предназначен для постановки диагноза, назначения лечения или самостоятельного выбора терапии. Решение принимает врач. Исследование описывает непосредственные реакции на обратную связь, а не долгосрочный эффект реабилитации.

Использовать следует только открытые или полностью обезличенные данные. Не вводите ФИО пациентов, медицинские документы и другую конфиденциальную информацию в чат или голосовой ввод. Текстовый запрос и агрегированная сводка передаются внешнему ИИ-сервису по HTTPS. При опасных симптомах следует обратиться за медицинской помощью; в экстренной ситуации в Казахстане — 103.

API-ключ в демонстрационной сборке может быть извлечён из APK. Не публикуйте APK с личным рабочим ключом. Для конкурсной демонстрации используйте отдельный ограниченный ключ, который можно отозвать после проверки. Для реального внедрения необходимы защищённая серверная авторизация, проверка форматов новых исследований, клиническая валидация и согласование требований к обработке медицинской информации.

## 8. Сборка из исходников (для разработчика)

Откройте корневую папку проекта в Android Studio. Используйте JDK 17 и установленные инструменты Android SDK (compileSdk 37 согласно конфигурации проекта). В `ai.properties` укажите собственный ключ `OPENROUTER_API_KEY`, при необходимости модель `OPENROUTER_MODEL` и отдельный `OPENAI_API_KEY` для голосового сервиса. Не передавайте действующие ключи вместе с исходным кодом.

Выполните Gradle Sync, затем сборку `assembleDebug` или Build APK(s). Стандартный путь результата: `app/build/outputs/apk/debug/app-debug.apk`.

**Комплект сдачи:** APK VostokLab, этот README, презентация из 10 слайдов и исходный код с инструкцией запуска; при необходимости отдельно приложите исходный архив данных исследования.
